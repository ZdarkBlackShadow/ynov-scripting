# Chapitre 8: Gestion des processus

## Consigne

- Créez une base de données MySQL avec une table de données, en vous assurant d'avoir les autorisations nécessaires.
- Utilisez le module `subprocess` pour vous connecter à la base de données MySQL à partir du script Python.
- Réalisez une requête SQL simple pour récupérer des données de la table créée dans la base de données.
